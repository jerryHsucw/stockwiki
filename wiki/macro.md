## 晶圓代工成熟製程漲價效應（集邦科技報告，延續至2027年）

| 製程 | 2025下半年 | 2026上半年 | 2026下半年 |
|------|-----------|-----------|-----------|
| 8吋（特定製程） | +5~10% | +5~15% | 0~10% |
| 12吋成熟製程 | 持平 | 持平 | 開始調漲，醞釀2027全面調漲 |
| 先進製程（台積電/三星/英特爾） | 持平 | +0~10% | 持平 |

**核心邏輯**：晶圓代工大廠（台積電/三星）縮減成熟製程產能轉向先進製程與先進封裝（毛利率更高）→供給減少；同時AI高毛利應用（電源管理IC、功率元件、矽中介層CoWoS-W、DTC深溝槽電容、IPD/IPC整合被動元件、PIC光子積體電路）排擠低毛利應用（影像感測器、面板驅動IC）產能→需求增加。8吋產能利用率已達88%，下半年上看90%。

**受惠個股**：聯電（2303）、世界（5347）等晶圓代工；德微（2469）、強茂（2481）、台半（5222）、矽力-KY（6415）、茂達（6138）等功率元件/電源管理IC（多檔已進處置，反映漲勢最強）。

| 項目 | 內容 |
|------|------|
| 事件起因 | 彭博報導Meta考慮出售多餘雲端運算容量，市場解讀為警訊 |
| 市場反應 | 費半昨日重挫6%（美光/Sandisk跌10%，應用材料/台積電/超微跌6-9%）；今日延燒至韓國股市熔斷、台北股市 |
| IMF警告 | 科技巨頭發行長天期債券（10-30年甚至百年債）購置AI硬體，但硬體折舊速度快，形成「期限錯配」；若AI商業化不如預期，恐現金流無法覆蓋長期成本 |
| 正面解讀 | Meta出售/轉租閒置算力，讓原本無變現能力的資本支出開始產生現金流，屬資產活化；降低其他開發者算力取得成本，有利AI長期發展；Meta股價昨日逆勢上漲 |
| 負面解讀 | 企業可直接租用而非自建資料中心，恐降低對AI硬體的新增資本支出需求，動搖市場樂觀敘事支點 |
| 那斯達克技術面 | 站回季線，前低24980/25014點未破，頭部尚未成形，暫不悲觳；若跌破頸線區＋季線，轉弱壓力將快速增加 |
| 短期定調 | 短空長多，AI硬體需求短期承壓，長期資本支出邏輯待驗證 |
